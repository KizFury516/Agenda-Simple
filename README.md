# Agenda

Pequeña agenda web separada por responsabilidades.

## Estructura

- `index.html` — estructura HTML y referencias a CSS/JS.
- `css/styles.css` — todos los estilos y temas claro/oscuro.
- `js/storage.js` — acceso a `localStorage`.
- `js/theme.js` — gestión del tema claro/oscuro.
- `js/agenda.js` — estado y lógica de la agenda, renderizado, formularios y detalle.
- `js/main.js` — inicialización y listeners de la interfaz.

## Ejecutar

Abre `index.html` en el navegador.

No necesita servidor ni dependencias de Node.js.
